v4.1.0
 * New: sync your settings in ANY Chromium browser, not just Chrome. Pick a
   provider in options: your browser account, a synced folder (OneDrive,
   Google Drive for Desktop, Dropbox, Syncthing...), your own WebDAV server
   (Nextcloud and friends), or Dropbox / OneDrive / Google Drive directly.
   All opt-in; settings stay on this machine by default.
 * New: download your settings as a file, or load one - handy for backups
   and moving between browsers.
 * Fix: favicons on the one-click save chips render again (the extension's
   host permissions had been silently invalid since the Manifest V3
   migration).
v4.0.0
 * New: light and dark themes. Follows your OS by default, with a
   System/Light/Dark choice in options, applied to all pages.
 * Options page redesigned into descriptive setting cards that explain what
   each setting actually does; images modernized.
 * The extension is now TabSetGo: a free and open source (MIT) hard fork of
   New Tab Redirect by Jim Schubert, with new icons and a new home at
   https://github.com/bilbospocketses/TabSetGo
 * Settings sync is now strictly opt-in: legacy flag values are normalized,
   the sync checkbox state roams with your other settings, and other machines
   can no longer overwrite this machine's URL while sync is off.
 * Removed the donation page and personal contact details from the original
   project; bugs and feature requests go to the GitHub issue tracker.
v3.2.0
 * Fix bug where the redirect URL was ignored (New Tab Redirect apps page shown
   instead) after the local copy of settings was lost. The new tab page now
   falls back to the synced URL and repairs local storage. (#235)
 * Fix bug where clicking Save without changing the URL could not repair a
   broken state (Chrome fires no storage change event for same-value writes).
   Options now always save to local storage directly, plus sync when enabled.
 * Fix crash in initial setup (JSON.parse called on an object) that could leave
   a fresh install without defaults.

v3.0

 * Added permissions:
    - "topSites": required to display top 10 visited sites
    - "management": required to allow user to display, launch, and
